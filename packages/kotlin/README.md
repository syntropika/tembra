# Tembra for Kotlin

This package provides the same Kotlin API for the JVM and Android.
`tembra-kotlin-jvm` contains a JVM library. `tembra-kotlin` contains an Android library.
Both use the Rust metadata kernel without React Native.

See the [Kotlin guide](../../docs/kotlin.md) for use.
See [Native builds](../../DEVELOP.md#native-builds) for build commands.
